## 🌟 About The Project
**Task Matrix** is a centralized web-based productivity hub designed to bring multiple utility applications under a single, sleek, and responsive interface. It features dynamic navigation, dark mode support, and seamless local storage management for each tool.

---

## 🛠️ Built With
* **HTML5**[cite: 3] - For structural layout and semantic elements.
* **CSS3**[cite: 3] - For modern styling, flexbox/grid layouts, and dark mode aesthetics.
* **JavaScript (ES6+)**[cite: 3] - For interactive application logic, DOM manipulation, and data persistence.

---

## 📱 Included Applications & Features

1. **✅ To-Do Manager**
   * Organize your daily tasks and get things done efficiently[cite: 4].
   * Add, complete, and delete tasks with local storage persistence.

2. **📝 Notes App**
   * Create, edit, and organize your personal notes easily[cite: 4].
   * Clean interface for quick jotting and content management.

3. **💰 Expense Tracker**
   * Track your daily income, expenses, and current balance.
   * Visual categorization of transactions.

4. **📅 Calendar**
   * Interactive calendar interface to view dates, track schedules, and manage monthly timelines.

5. **🧮 Calculator**
   * Functional standard calculator for quick mathematical calculations.

6. **🔑 Random Password Generator**
   * Generate secure, randomized passwords with customizable length and character sets.
